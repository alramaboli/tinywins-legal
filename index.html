Information TinyWins stores

TinyWins is a habit tracker. The app stores the information needed for the features you use:

  • Habit name and optional note or description.
  • Category, icon selection, and selected weekdays.
  • Habit creation and update dates, and whether a habit is archived.
  • Completion dates and completion timestamps.
  • Whether onboarding has been completed.

Habit names and notes are free text. If you choose to enter personal or health-related details there, those details are stored with that habit. TinyWins does not have a separate medical-record or health-measurement form.

The app uses the device's current date and time to date habits and completions and calculate progress. Habit records also have an internal local identifier.

Where information is stored and sent

The reviewed app code saves habit records in a SQLite database named tinywins.db in the app's local storage. The reviewed application source contains no account service, cloud synchronization, analytics or advertising code, or app-level code that uploads habit records to a TinyWins server. Habit tracking can be used offline.

The Android app manifest includes the INTERNET permission. That permission permits network access; by itself it does not show that the app sends habit information. Network behavior and all included SDKs must be checked again in the final production bundle before publication.

Installing or updating the app uses the app store through which it is distributed. Google Play, the device operating system, and any enabled device-backup service operate under their own terms and privacy policies.

Accounts, analytics, and third parties

The reviewed app implementation does not provide user registration, login, or authentication. No analytics, advertising, or crash-reporting SDK is declared in the app's direct dependencies or observed in the generated Android native package list. The app does not have a TinyWins server account to which habit data is sent.

TinyWins is built with Expo and React Native and includes native modules for local SQLite storage, navigation, gestures, and screen layout. The final production bundle may differ from the reviewed project snapshot; the publisher must inspect all final direct and transitive SDKs and their data practices before making store declarations.

Permissions and device information

The reviewed app screens do not request access to contacts, location, camera, microphone, photos, or files. The Android manifest also declares Internet access. The app code reviewed does not read a device advertising identifier or provide an account/profile field.

Retention and deletion

Habit data remains in the local database until you delete a habit, use Settings → Reset all data, or the app's data is removed by the operating system. Deleting a habit also deletes its completion history. Reset all data removes all habits, completion records, and onboarding state from the app database. Archiving a habit only marks it archived; it does not delete it.

TinyWins does not provide an account, so it has no account-deletion workflow or server-side user profile to delete. The app does not claim that database deletion securely overwrites storage blocks.

Device backups

The reviewed Android manifest sets android:allowBackup="true". This permits Android backup and transfer mechanisms, but the exact eligibility and behavior for this database have not been verified across devices and Android versions. A device backup may retain a copy after data is removed from the app. Check the final release backup configuration before publication. Backup behavior on other platforms depends on their operating-system settings and has not been verified here.

Security

The database is stored in the app's local storage and is subject to the device operating system's app isolation. The app uses SQLite query parameters for database writes. The reviewed project does not configure database-level encryption or a separate encryption key. Do not treat the database as encrypted by the app, and use the device's screen lock and security settings to protect access to your device.
